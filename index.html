Honest Failure Case (Semantic Drift)

Because the standard RAG only did a semantic search, it fetched general "remote work guidelines" chunks instead of the specific "travel expenses" rules which were semantically distant. The LLM then hallucinated that personal trips are covered.

The Fix: Hybrid Search (BM25 + Dense) combined with a Cross-Encoder Reranker brings the exact clause to the top 3 results, resolving the drift. Try switching to Advanced Reranked.

RAG System: Production-Grade Knowledge Retrieval

A high-performance RAG pipeline leveraging semantic embeddings, hybrid keyword matching, and cross-encoder reranking over corporate knowledge bases.

Engineering Trade-offs & Architecture

  • Dense (Vector) vs. Sparse (BM25) Search: Dense captures semantics, sparse matches specific ID codes/proper nouns. Used reciprocal rank fusion (RRF) to merge ranks.
  • Chunk Strategy: Semantic chunking based on header hierarchy rather than fixed token length, minimizing split contexts.

What Broke & How It Was Solved

"Initially, search query length drift led to retrieval of garbage chunks, causing GPT-4 to hallucinate expense coverage rules. We implemented **Cohere Rerank v3** post-retrieval, lowering Hallucination Rate from 12.4% to under 0.8%."
Qdrant LlamaIndex Cohere Rerank Python

Autonomous Task Agents: ReAct loops & Tool-Use

An agent framework designed to complete complex operations (like market data aggregation and research summarization) autonomously via a tool-calling execution cycle.

Engineering Trade-offs & Architecture

  • State Management: Built with stateful LangGraph instead of linear chains to allow complex backtracking, loops, and human-in-the-loop validation checkpoints.
  • Tool Safety: Sandboxed terminal and query environments to prevent prompt injection or execution of malicious user commands.

What Broke & How It Was Solved

"The agent often entered infinite thought loops when tools returned empty or noisy data. We fixed this by introducing **Structured Outputs** (JSON schema formatting) and a strict loop counter handler that forces human escalation after 5 repeated tool failures."
LangGraph Tool Calling FastAPI Docker Sandbox

Eval Harness: Automated Quality Assertion

A CI/CD-linked test suite running evaluation metrics (Retrieval Recall, Faithfulness, Semantic Similarity) over golden datasets.

Engineering Trade-offs & Architecture

  • LLM-as-a-Judge: Used GPT-4o-mini to grade complex outputs against reference ground truth. This decreased evaluation costs by 90% compared to GPT-4o.
  • Continuous Testing: Integrates into Github Actions. Commits that degrade recall or prompt faithfulness scores by >5% trigger build failures.

What Broke & How It Was Solved

"LLM judges are highly biased by position and length of the answers. We solved this by using **Ragas** metrics combined with deterministic exact-match checks for critical outputs (like IDs and numbers) to prevent judge hallucinations."
